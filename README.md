## About

TheGameBoxd is a web application for people who want a place to keep track of what they play. Taking inspiration from [Letterboxd](https://letterboxd.com/), the project brings the idea of a social movie diary into the world of video games.

Users can explore a game catalog, keep personal lists, mark games as played or favorites, and leave ratings and written reviews.

This project was originally developed as a **Database course final project**. Database modeling, relationships, constraints, and data operations are an important part of its foundation.

## Features
The repository implements the following areas:
- Game discovery: search for games and retrieve game information from the IGDB API.
- Game catalog: browse a game library and filter games by genre.
- Personal lists: create and manage named watchlists.
- Game status: associate games with lists and track their play status.
- Ratings and reviews: rate games, write reviews, see a game's reviews, and calculate its average user rating.
- User accounts: register, log in, and manage profile information.
- Profiles: update profile details and upload a profile picture.
- Rankings: display game rankings based on user ratings.
